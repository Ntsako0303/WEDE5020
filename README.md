#### Website Goals and Objectives
The goal for the website is for customers to be able to navigate the website with any trouble. We 
want them to be able to captured by the experience of buying online and provide a convenient and 
efficient alternative to standard shopping. The aim is to provide customers with a variety, and 
savings by allowing consumers to shop anytime, compare prices easily, access detailed product 
information, and enjoy secure, personalized purchasing experiences.
We must that we regularly check for any errors, make sure that the website is working they way 
want it to work for the best customer experience
